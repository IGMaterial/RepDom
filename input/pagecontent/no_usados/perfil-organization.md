# Perfil OrganizationDO

Este perfil representa organizaciones y establecimientos de salud dentro de la guía.

## Propósito

Permite modelar instituciones, centros de salud, unidades organizacionales y otros actores institucionales con datos básicos de identificación y ubicación.

## Restricciones principales

- Se exige al menos un identificador.
- El nombre de la organización es obligatorio.
- Se permiten datos de telecomunicaciones y dirección.
- La relación jerárquica con otra organización puede expresarse mediante partOf.

## Uso recomendado

Se utiliza para representar custodios de documentos, instituciones responsables y unidades administrativas asociadas a la atención.
