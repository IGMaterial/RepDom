# Perfil PractitionerDO

Este perfil representa a profesionales de salud en la guía Core de República Dominicana.

## Propósito

Permite describir los datos de identificación y formación profesional de personas que actúan como autores o responsables de atención clínica.

## Restricciones principales

- Se exige al menos un identificador.
- El sistema y el valor del identificador son obligatorios.
- El nombre del profesional es obligatorio.
- Se soporta la inclusión de extensiones para segundo apellido.
- La calificación profesional puede incluir un identificador y un código.

## Uso recomendado

Se emplea para representar autores de documentos clínicos y responsables de registros en recursos relacionados.
