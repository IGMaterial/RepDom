# Perfil AllergyIntoleranceDO

Este perfil describe alergias, intolerancias y reacciones adversas.

## Propósito

Permite registrar eventos adversos relacionados con sustancias, medicamentos o exposiciones, con información clínica relevante para el cuidado del paciente.

## Restricciones principales

- El paciente es obligatorio.
- El código de la alergia o intolerancia es obligatorio.
- Se soportan estados clínicos y de verificación.
- Se pueden incluir reacciones y su severidad.

## Uso recomendado

Se utiliza en documentos clínicos, historiales y flujos de intercambio donde se requiere representar eventos de hipersensibilidad o reacciones adversas.
