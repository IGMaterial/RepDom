# Perfil BundleDocDO

Este perfil define un Bundle documental orientado a la agregación de recursos clínicos de un documento IPS.

## Propósito

Permite agrupar recursos de composición, paciente, organización y profesional dentro de un mismo bundle documental.

## Restricciones principales

- El bundle debe incluir la composición como parte central del documento.
- Se espera que el paciente, la organización y el profesional estén representados con los perfiles definidos en esta guía.
- La estructura del bundle se orienta a escenarios de intercambio documental.

## Uso recomendado

Se utiliza en flujos donde se necesita empaquetar un documento clínico y sus recursos relacionados en una unidad de intercambio.
